# CopyPaste v0.2.0 Release Notes

## Highlights

- Added `Classic` and `Modern` interface styles.
- Added a redesigned Modern settings window with section navigation.
- Added a Modern main panel with a three-column layout:
  - left filters and pinboards
  - center clipboard history list
  - right preview and actions
- Kept `Classic` as the default interface style for existing users.
- Updated the macOS bundle version to `0.2.0`.

## Notes

- Clipboard history, pinboards, search, filters, paste behavior, and Accessibility permission behavior reuse the existing data and action model.
- The release build is still ad-hoc signed and not notarized.
